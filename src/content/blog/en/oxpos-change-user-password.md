A cashier forgot their password, or a staff member just left: both need a quick password change. This tutorial shows both ways to do it in [OxPOS](/oxpos) in under two minutes.

## Option 1: The owner resets a user’s password

1. **Open user management** from the dashboard.
2. **Choose the user** and select reset password.
3. **Enter a new temporary password.**
4. **Keep “must change password” switched on,** so the user sets their own password at their next login.

The admin can reset a password without knowing the old one.

## Option 2: A user changes their own password

1. **Open My Account.**
2. **Enter the current password,** then the new password and the confirmation.
3. **Save.** A confirmation message shows the change is done.

## Key points

- The minimum password length is **8 characters**.
- New users are asked to change their password at **first login**.
- The admin can **reset** any user’s password from the dashboard.

## Security tips

- Change cashier passwords regularly, and always when an employee leaves.
- Never share one login between several people, so every sale is credited to the right person.
- Use passwords that are easy to remember but hard to guess, such as a short phrase with numbers.
